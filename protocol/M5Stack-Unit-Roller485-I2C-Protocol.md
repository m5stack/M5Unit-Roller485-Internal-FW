# M5Stack Unit Roller485 I2C 控制协议

| 项目 | 内容 |
| :--- | :--- |
| 文档版本 | `V2.1` |
| 适用设备 | M5Stack Unit Roller485 |
| 适用固件 | `V2` |
| 产品设备 ID | `0x01` |
| 发布日期 | `2026-08-24` |
| 文档状态 | Release |

本文档定义 Unit Roller485 作为 I2C 从机时的寄存器访问方法、数据格式、参数范围和操作副作用。

---

## 1. 基本信息

| 项目 | 说明 |
| :--- | :--- |
| 总线 | I2C，从机模式 |
| 默认 7 位地址 | `0x64` |
| 有效地址范围 | `0x08 ~ 0x77` |
| 通信速率 | 由主机决定，设备不要求固定频率 |
| 寄存器地址宽度 | 8 bit |
| 多字节端序 | 小端，低地址存放最低有效字节 |
| 产品设备 ID | `0x01` |
| 固件版本 | `2` |
| 文档版本 | `V2.1` |

### 1.1 访问权限

| 权限 | 含义 |
| :--- | :--- |
| `R` | 只读 |
| `W` | 只写 |
| `R/W` | 可读写 |
| `Reserved` | 保留，不应访问 |

### 1.2 通用访问流程

写事务：

```text
START + SlaveAddr(W) + RegAddr + Data0 [+ Data1 ...] + STOP
```

读事务：

```text
START + SlaveAddr(W) + RegAddr + RESTART + SlaveAddr(R) + Data0 [+ Data1 ...] + STOP
```

一次写入必须完全落在一个支持的寄存器块内，超出块尾的写入被拒绝。读取可以从多字节
字段中间地址开始，但长度不能超过当前块剩余长度。未知单字节地址读取返回 `0x00`。

### 1.3 数据类型和换算

- `UINT8` 为无符号 8 位整数；`UINT16` 按 `Byte0 + (Byte1 << 8)` 组合。
- `INT32`/`UINT32` 均为小端；`INT32` 使用二补码解释。
- `X100` 参数的工程值为原始整数除以 `100`。
- 圈内角度为小端 `UINT16`，单位 `0.01 deg`，范围 `0 ~ 35999`。

## 3. 地址约定

| 地址/地址范围 | 分区 | 说明 |
| :--- | :--- | :--- |
| `0x00 ~ 0x0F` | 电机控制与状态 | 输出、模式、保护和错误 |
| `0x10 ~ 0x12` | RS485 配置 | ID、波特率和 RGB 亮度 |
| `0x20 ~ 0xC3` | 目标、反馈和 PID | 由总览表列出的离散寄存器块组成 |
| `0xE0 ~ 0xEB` | 设备识别 | 96-bit UID，只读 |
| `0xF0 ~ 0xF4` | 保存、校准、产品信息 | 固定系统寄存器 |
| `0xFE ~ 0xFF` | 版本、地址 | 固定系统寄存器 |

未列出的地址为保留地址。主机不应依赖保留地址返回 `0` 的当前实现。

| 地址 | 名称 | 写入规则和注意事项 |
| :--- | :--- | :--- |
| `0xF0` | 保存参数 | 仅写入 `1` 生效，写 Flash，避免高频调用 |
| `0xF1` | 启动校准 | 写非零值；过压或忙时可能忽略 |
| `0xF2` | 保存校准 | 写非零值；仅保存有效校准结果 |
| `0xFE` | 固件版本 | 只读，固定返回 `2` |
| `0xFF` | I2C 地址 | `0x08~0x77`，保存并立即重新初始化 I2C |

## 4. 寄存器详情

### 4.1 电机控制与状态：`0x00 ~ 0x0F`

| 地址 | 参数 | 权限 | 类型/范围 | 说明 |
| :--- | :--- | :--: | :--- | :--- |
| `0x00` | 电机输出 | R/W | `UINT8`，`0/1` | `0` 关闭，`1` 开启，立即生效 |
| `0x01` | 控制模式 | R/W | `UINT8`，`1~4` | `1` 速度，`2` 位置，`3` 电流，`4` 编码器 |
| `0x02~0x09` | 保留 | Reserved | 不应访问 | 当前读取返回 `0`，写入不生效 |
| `0x0A` | 位置超范围保护 | R/W | `0/1` | 位置范围保护开关 |
| `0x0B` | 解除堵转保护 | W | 非零触发 | 清除堵转错误和保护状态 |
| `0x0C` | 系统状态 | R | `0/1/2` | `0` 待机，`1` 运行，`2` 错误 |
| `0x0D` | 错误码 | R | 位组合 | bit0 过压，bit1 堵转，bit2 位置超范围 |
| `0x0E` | 按键模式切换 | R/W | `0/1` | 允许按键切换模式 |
| `0x0F` | 堵转保护 | R/W | `0/1` | 堵转保护开关 |

模式切换在堵转错误未解除时不会生效。写 `0x0B` 后主机应重新读取 `0x0C`、`0x0D`。

### 4.2 RS485 配置：`0x10 ~ 0x12`

| 地址 | 参数 | 权限 | 类型/范围 | 说明 |
| :--- | :--- | :--: | :--- | :--- |
| `0x10` | RS485 Motor ID | R/W | `UINT8`，`0~255` | RS485 目标 ID |
| `0x11` | RS485 Baud Index | R/W | `0~2` | `0=115200`，`1=19200`，`2=9600` |
| `0x12` | RGB Brightness | R/W | `0~100` | RGB 亮度百分比 |

字段修改立即作用于运行参数；需要掉电保存时另发 `0xF0=1`。波特率切换完成后，主机
必须使用新波特率。

### 4.3 位置环最大电流：`0x20 ~ 0x23`

`INT32` 小端，工程值 `mA = raw / 100`。写入后会经过 PID 电流限幅接口，不能绕过
固件允许的最大相电流。

### 4.4 RGB、输入电压、温度和计数：`0x30 ~ 0x3F`

| 地址 | 参数 | 权限 | 类型/换算 | 说明 |
| :--- | :--- | :--: | :--- | :--- |
| `0x30` | RGB Blue | R/W | `UINT8`，`0~255` | 蓝色分量 |
| `0x31` | RGB Green | R/W | `UINT8`，`0~255` | 绿色分量 |
| `0x32` | RGB Red | R/W | `UINT8`，`0~255` | 红色分量 |
| `0x33` | RGB Mode | R/W | `0/非零` | `0` 系统颜色，非零用户颜色 |
| `0x34~0x37` | VIN | R | `INT32`，V = raw / 100 | 输入电压 |
| `0x38~0x3B` | MCU Temperature | R | `INT32`，deg C | MCU 内部温度 |
| `0x3C~0x3F` | Encoder Counter | R/W | `INT32` 小端 | 编码器/旋钮计数 |

RGB 写入立即显示，掉电保存仍需 `0xF0=1`。

### 4.5 速度参数：`0x40 ~ 0x63`

| 地址 | 参数 | 权限 | 类型/换算 | 说明 |
| :--- | :--- | :--: | :--- | :--- |
| `0x40~0x43` | 速度目标 | R/W | `INT32`，rpm = raw / 100 | 速度模式目标 |
| `0x50~0x53` | 速度环最大电流 | R/W | `INT32`，mA = raw / 100 | 速度环电流上限 |
| `0x60~0x63` | 实际速度 | R | `INT32`，rpm = raw / 100 | 实际速度 |

例如目标 `60.00 rpm` 的原始值为 `6000`，小端字节为 `70 17 00 00`。

### 4.6 速度 PID：`0x70 ~ 0x7B`

| 地址 | 参数 | 类型 | 缩放 |
| :--- | :--- | :--- | :---: |
| `0x70~0x73` | 速度 Kp | `UINT32` 小端 | 实际 Kp = raw / 100000 |
| `0x74~0x77` | 速度 Ki | `UINT32` 小端 | 实际 Ki = raw / 10000000 |
| `0x78~0x7B` | 速度 Kd | `UINT32` 小端 | 实际 Kd = raw / 100000 |

PID 参数写入运行配置；使用 `0xF0=1` 保存到 Flash。

### 4.7 位置参数：`0x80 ~ 0x9D`

| 地址 | 参数 | 权限 | 类型/单位 |
| :--- | :--- | :--: | :--- |
| `0x80~0x83` | 旧格式目标位置 | R/W | `INT32`，0.01 deg |
| `0x88~0x8B` | 目标圈数 | R/W | `INT32`，整圈数 |
| `0x8C~0x8D` | 目标圈内角度 | R/W | `UINT16`，0.01 deg，`0~35999` |
| `0x90~0x93` | 旧格式实际位置 | R | `INT32`，0.01 deg |
| `0x98~0x9B` | 实际圈数 | R | `INT32`，整圈数 |
| `0x9C~0x9D` | 实际圈内角度 | R | `UINT16`，0.01 deg，`0~35999` |

位置关系为：

```text
legacy_position_cdeg = turns * 36000 + angle_cdeg
```

当结果超出旧格式 `INT32` 范围时，旧格式按最大或最小值限幅；扩展圈数和圈内角度
仍保存实际的大范围位置。写入任一表示方式会同步更新另一种表示。非法圈内角度不生效。

### 4.8 位置 PID：`0xA0 ~ 0xAB`

| 地址 | 参数 | 类型 | 缩放 |
| :--- | :--- | :--- | :---: |
| `0xA0~0xA3` | 位置 Kp | `UINT32` 小端 | 实际 Kp = raw / 100000 |
| `0xA4~0xA7` | 位置 Ki | `UINT32` 小端 | 实际 Ki = raw / 10000000 |
| `0xA8~0xAB` | 位置 Kd | `UINT32` 小端 | 实际 Kd = raw / 100000 |

### 4.9 电流参数：`0xB0 ~ 0xC3`

| 地址 | 参数 | 权限 | 类型/换算 | 说明 |
| :--- | :--- | :--: | :--- | :--- |
| `0xB0~0xB3` | 电流目标 | R/W | `INT32`，mA = raw / 100 | 电流模式目标 |
| `0xC0~0xC3` | 实际电流 | R | `INT32`，mA = raw / 100 | 实际相电流 |

电流目标受固件控制器的最大电流范围限制。

### 4.10 设备 UID：`0xE0 ~ 0xEB`

| 地址 | 内容 | 权限 |
| :--- | :--- | :--: |
| `0xE0~0xE3` | UID Word 0 / Byte0~3 | R |
| `0xE4~0xE7` | UID Word 1 / Byte4~7 | R |
| `0xE8~0xEB` | UID Word 2 / Byte8~11 | R |

UID 是 STM32 固有 96-bit 值。主机建议从 `0xE0` 连续读取 12 字节；从中间字节读取
时返回该位置及后续 UID 字节，不支持写入。

### 4.11 保存参数：`0xF0`

仅当写事务为 `F0 01` 时执行 Flash 保存。保存对象包括目标、电流限制、PID、RS485
配置和 RGB 配置。保存操作不应高频调用。

### 4.12 编码器校准：`0xF1 ~ 0xF3`

1. 向 `0xF1` 写非零值启动校准；过压时请求可能被忽略。注意：`0xF1` 分支只检查过压状态，不检查校准忙状态。
2. 周期读取 `0xF3`，`1` 表示校准中，`0` 表示空闲。
3. 校准完成且结果有效后，向 `0xF2` 写非零值保存偏移到 Flash。

`0xF2` 不会启动校准，不要在 `0xF3=1` 时保存结果。

### 4.13 产品设备 ID：`0xF4`

只读，固定返回 `0x01`，用于区分 Roller485 产品类型。

### 4.14 固件版本：`0xFE`

只读，当前 Roller485 V2 固件返回 `0x02`。

### 4.15 I2C 地址：`0xFF`

有效范围为 `0x08 ~ 0x77`，出厂默认值为 `0x64`。超出范围、与当前地址相同或数据
长度不为 1 的写入不生效。有效地址写入会自动保存到 Flash，随后立即重新初始化 I2C；
主机后续事务必须使用新地址。

## 5. 逐寄存器操作说明

本节中的“写入长度”不包含 1 byte 寄存器地址。多字节寄存器允许从块内中间地址开始
读写剩余字节，但主机应优先一次传输完整字段，避免控制任务在部分字节更新期间读取到
过渡值。只读寄存器的写入不会生效；未定义地址不应访问。

### 5.1 电机输出 `0x00`

| 项目 | 说明 |
| :--- | :--- |
| 权限 | R/W |
| 数据 | `uint8_t`，1 byte；`0` 关闭，`1` 开启 |
| 写入行为 | 立即控制功率输出；存在过压、堵转保护或非法模式时，开启请求可能被保护逻辑拒绝 |
| 读取结果 | 当前输出状态，固定返回 `0` 或 `1` |

### 5.2 控制模式 `0x01`

| 值 | 模式 |
| :---: | :--- |
| `1` | 速度模式 |
| `2` | 位置模式 |
| `3` | 电流模式 |
| `4` | 编码器/旋钮模式 |

写入长度为 1 byte。合法值立即生效；堵转保护未解除时模式切换可能被拒绝。切换模式会按
控制需要清理 PID 积分或初始化编码器旋钮逻辑。其他值被忽略，读取仍返回当前有效模式。

### 5.3 位置范围保护 `0x0A`

R/W，1 byte。`0` 禁用，非零启用。该寄存器只修改运行值；需要掉电保持时写 `0xF0=1`。

### 5.4 解除堵转保护 `0x0B`

W，1 byte。写非零值清除堵转错误、恢复计数和堵转保护状态；写 `0` 不执行。该命令不会
自动开启电机，执行后应读取 `0x0C`、`0x0D` 确认状态，再按需要写 `0x00=1`。

### 5.5 系统状态 `0x0C`

R，1 byte：`0` 待机、`1` 运行、`2` 错误。该状态用于描述电机控制状态，不是 I2C
总线错误码。

### 5.6 错误码 `0x0D`

R，1 byte，允许多个错误位同时置位。

| Bit | 掩码 | 说明 |
| :---: | :---: | :--- |
| bit0 | `0x01` | 输入过压 |
| bit1 | `0x02` | 电机堵转 |
| bit2 | `0x04` | 位置超出允许范围 |
| bit7~3 | - | 保留 |

### 5.7 按键模式切换 `0x0E`

R/W，1 byte。`0` 禁止本机按键切换模式，非零允许。需要掉电保持时写 `0xF0=1`。

### 5.8 堵转保护使能 `0x0F`

R/W，1 byte。`0` 禁用，非零启用。关闭该功能不会自动清除已经产生的堵转错误；已有
堵转错误仍应通过 `0x0B` 解除。需要掉电保持时写 `0xF0=1`。

### 5.9 RS485 电机 ID `0x10`

R/W，`uint8_t`，1 byte，范围 `0x00~0xFF`。写入后更新运行时 RS485 ID；使用
`0xF0=1` 保存后才保证掉电保持。后续 RS485 请求必须使用新 ID。

### 5.10 RS485 波特率档位 `0x11`

| 值 | 波特率 |
| :---: | :---: |
| `0` | 115200 bps |
| `1` | 19200 bps |
| `2` | 9600 bps |

R/W，1 byte。大于 `2` 的写入被忽略。使用 `0xF0=1` 保存后掉电保持；主机切换到
RS485 通信时必须使用读取到的档位。

### 5.11 RGB 亮度 `0x12`

R/W，`uint8_t`，1 byte，范围 `0~100`，单位为百分比。合法值立即刷新 LED；超范围
写入被忽略。使用 `0xF0=1` 保存后掉电保持。

### 5.12 位置环最大电流 `0x20~0x23`

R/W，4 byte，小端 `int32_t`，原始值单位为 `0.01 mA`，即
`current_mA = raw / 100`。写入值经过位置 PID 电流限幅接口，读取返回实际采用的限幅值。

### 5.13 RGB 颜色与模式 `0x30~0x33`

| 地址 | 字段 | 类型/范围 |
| :---: | :--- | :--- |
| `0x30` | Blue | `uint8_t`，`0~255` |
| `0x31` | Green | `uint8_t`，`0~255` |
| `0x32` | Red | `uint8_t`，`0~255` |
| `0x33` | 显示模式 | `0` 使用系统状态颜色，非零使用用户颜色 |

R/W，共 4 byte。颜色顺序是 B、G、R，不是 RGB888 的 R、G、B 顺序。颜色分量写入后
立即更新用户颜色；亮度由 `0x12` 单独控制。使用 `0xF0=1` 保存后掉电保持。

### 5.14 输入电压 `0x34~0x37`

R，4 byte，小端 `int32_t`。`voltage_V = raw / 100`。例如返回 `D2 04 00 00` 时，
原始值为 `1234`，输入电压为 `12.34 V`。

### 5.15 MCU 温度 `0x38~0x3B`

R，4 byte，小端 `int32_t`，单位 `deg C`。该值来自 MCU 内部温度测量，用于设备状态
监视，不等同于电机绕组温度或环境精密温度。

### 5.16 编码器/旋钮计数 `0x3C~0x3F`

R/W，4 byte，小端 `int32_t`。编码器模式下读取当前旋钮计数；写入可重设计数基准。
在其他控制模式下不应把该字段当作机械位置反馈，机械位置应读取 `0x90` 或 `0x98`。

### 5.17 速度目标 `0x40~0x43`

R/W，4 byte，小端 `int32_t`。`speed_rpm = raw / 100`；正负号决定旋转方向。写入只
更新目标值，要让电机转动还必须设置速度模式并开启输出。

### 5.18 速度环最大电流 `0x50~0x53`

R/W，4 byte，小端 `int32_t`，`current_mA = raw / 100`。写入经过速度 PID 电流限幅
接口，读取返回实际采用值。

### 5.19 实际速度 `0x60~0x63`

R，4 byte，小端 `int32_t`，`speed_rpm = raw / 100`。返回值带符号，方向与速度目标
使用同一符号约定。

### 5.20 速度 PID `0x70~0x7B`

| 地址 | 参数 | 原始类型 | 换算 |
| :--- | :--- | :--- | :--- |
| `0x70~0x73` | Kp | `uint32_t` | `Kp = raw / 100000` |
| `0x74~0x77` | Ki | `uint32_t` | `Ki = raw / 10000000` |
| `0x78~0x7B` | Kd | `uint32_t` | `Kd = raw / 100000` |

R/W，共 12 byte，小端。允许从任一字段中间地址读写，但建议一次完整写入一个 4 byte
系数。写入当前选中的速度 PID 组并清理相应积分状态；`0xF0=1` 用于掉电保存。

### 5.21 旧格式目标位置 `0x80~0x83`

R/W，4 byte，小端 `int32_t`，单位 `0.01 deg`。该接口用于兼容旧主机；写入后同步
更新扩展目标圈数和圈内角度。超出旧格式可表示范围的位置应使用 `0x88~0x8D`。

### 5.22 扩展目标位置 `0x88~0x8D`

| 地址 | 字段 | 类型/单位 |
| :--- | :--- | :--- |
| `0x88~0x8B` | 目标圈数 | 小端 `int32_t`，整圈 |
| `0x8C~0x8D` | 目标圈内角度 | 小端 `uint16_t`，`0.01 deg`，范围 `0~35999` |

R/W，共 6 byte。设备以“圈数 + 圈内角度”组成目标位置；角度大于 `35999` 时整次写入
不生效。允许只更新圈数或角度，但建议一次写满 6 byte。写入后同步更新旧格式目标位置。

### 5.23 旧格式实际位置 `0x90~0x93`

R，4 byte，小端 `int32_t`，单位 `0.01 deg`。为兼容旧主机而保留；当长期累计位置超出
`int32_t` 表示范围时返回限幅值，不适合无限圈长期计数。

### 5.24 扩展实际位置 `0x98~0x9D`

| 地址 | 字段 | 类型/单位 |
| :--- | :--- | :--- |
| `0x98~0x9B` | 实际圈数 | 小端 `int32_t`，整圈 |
| `0x9C~0x9D` | 实际圈内角度 | 小端 `uint16_t`，`0.01 deg`，范围 `0~35999` |

R，共 6 byte。长期运行或需要防止旧位置累计溢出时，应优先读取该位置模型。

### 5.25 位置 PID `0xA0~0xAB`

| 地址 | 参数 | 原始类型 | 换算 |
| :--- | :--- | :--- | :--- |
| `0xA0~0xA3` | Kp | `uint32_t` | `Kp = raw / 100000` |
| `0xA4~0xA7` | Ki | `uint32_t` | `Ki = raw / 10000000` |
| `0xA8~0xAB` | Kd | `uint32_t` | `Kd = raw / 100000` |

R/W，共 12 byte，小端。写入当前选中的位置 PID 组并清理相应积分状态；建议逐个完整
写入 4 byte 系数，使用 `0xF0=1` 保存。

### 5.26 电流目标 `0xB0~0xB3`

R/W，4 byte，小端 `int32_t`，`current_mA = raw / 100`。允许范围为
`-120000~120000`（即 `-1200.00~1200.00 mA`），超出时由固件限幅。写入只更新电流
目标；要产生输出还必须设置电流模式并开启电机。

### 5.27 实际电流 `0xC0~0xC3`

R，4 byte，小端 `int32_t`，`current_mA = raw / 100`。返回带符号的滤波相电流反馈。

### 5.28 STM32 UID `0xE0~0xEB`

R，12 byte。推荐从 `0xE0` 连续读取 12 byte；返回顺序为 UID Word0、Word1、Word2，
每个 Word 内采用小端字节序。UID 为芯片唯一标识，不可修改。从中间地址开始读取时，
设备返回该地址到 `0xEB` 的剩余字节。

### 5.29 保存参数 `0xF0`

W，1 byte。仅写入 `1` 执行 Flash 保存，其他值不执行。Flash 擦写寿命有限，不应周期
调用；应在一组配置修改完成后调用一次。

### 5.30 启动编码器校准 `0xF1`

W，1 byte。写非零值请求启动校准；过压状态下请求被忽略。校准期间电机会动作，主机应
确保机构无阻挡并保持供电。启动后轮询 `0xF3`，不要用固定短延时判断完成。

### 5.31 保存编码器校准结果 `0xF2`

W，1 byte。校准完成后写非零值，将当前校准偏移应用并写入 Flash。推荐流程为：启动
`0xF1`、等待 `0xF3=0`、确认电机已停止，再写 `0xF2=1`。校准中不要保存。

### 5.32 编码器校准忙状态 `0xF3`

R，1 byte。`1` 表示校准进行中，`0` 表示当前不忙。`0` 仅表示校准过程结束，不代表
结果已经写入 Flash；仍需执行 `0xF2`。

### 5.33 产品设备 ID `0xF4`

R，1 byte，Roller485 固定返回 `0x01`。该值表示产品型号，不是 I2C 地址或 RS485 ID。

### 5.34 固件版本 `0xFE`

R，1 byte，Roller485 V2 返回 `0x02`。这是应用固件主版本号，不是产品设备 ID。

### 5.35 I2C 地址 `0xFF`

R/W，1 byte，7 位地址范围 `0x08~0x77`，默认 `0x64`。仅完整写入 1 byte、地址合法且
不同于当前地址时生效；有效写入会立即保存到 Flash 并重新初始化 I2C。写事务结束后，
主机必须改用新地址；若通信恢复失败，应扫描新旧地址确认设备位置。

## 6. 通信示例

### 6.1 读取实际速度

```text
START + 0x64(W) + 0x60 + RESTART + 0x64(R) + Speed0 Speed1 Speed2 Speed3 + STOP
```

将返回的有符号小端整数除以 `100` 得到 rpm。

### 6.2 设置速度目标

设置 `60.00 rpm`，原始值为 `6000`，小端字节为 `70 17 00 00`：

```text
START + 0x64(W) + 0x40 + 70 17 00 00 + STOP
```

### 6.3 读取 UID 和设备信息

```text
START + 0x64(W) + 0xE0 + RESTART + 0x64(R) + 12 bytes + STOP
START + 0x64(W) + 0xF4 + RESTART + 0x64(R) + 1 byte + STOP
START + 0x64(W) + 0xFE + RESTART + 0x64(R) + 1 byte + STOP
```

### 6.4 保存参数和修改地址

```text
START + 0x64(W) + 0xF0 + 01 + STOP
START + 0x64(W) + 0xFF + 0x66 + STOP
```

第二条写入完成后，后续访问地址变为 `0x66`。

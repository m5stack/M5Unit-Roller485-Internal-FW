## 2. 数据帧格式

### 2.1 普通控制帧

普通控制请求为 15 字节，设备响应为 17 字节。请求帧不带 `AA 55` 帧头；只有设备响应
带帧头：

```text
请求：Cmd MotorID Data0 Data1 ... Data11 CRC8
响应：AA 55 RespCmd MotorID Data0 Data1 ... Data11 CRC8
```

| 字段 | 长度 | 说明 |
| :--- | :--: | :--- |
| 帧头 | 请求无；响应 2 | 响应固定为 `0xAA 0x55`，不参与 CRC |
| Cmd | 1 | 请求命令；响应通常为请求 Cmd + `0x10` |
| MotorID | 1 | 目标或响应电机 ID |
| Data | 12 | 命令参数，未使用字节填 `0` |
| CRC8 | 1 | 校验 Cmd、MotorID 和 12 字节 Data |

### 2.2 短查询帧

状态/扩展回读查询使用 4 字节请求，且请求不带帧头：

```text
请求：Cmd MotorID Option CRC8
```

普通回读响应为 20 字节：

```text
AA 55 RespCmd MotorID Data0 ... Data14 CRC8
```

未使用的 Data 字节为 `0`。查询 Option 应为 `0`，响应数据从 Data0 开始。

### 2.3 I2C 转发帧

| 命令 | 请求总长 | 响应 | 响应总长 | 用途 |
| :--- | :---: | :--- | :---: | :--- |
| `0x60` | 8 | `0x70` | 27 | 寄存器 I2C 读 |
| `0x61` | 25 | `0x71` | 6 | 寄存器 I2C 写 |
| `0x62` | 5 | `0x72` | 27 | 原始 I2C 读 |
| `0x63` | 25 | `0x73` | 6 | 原始 I2C 写 |

`0x60`/`0x61` 的 Data 字段为：I2C 7 位地址、寄存器地址长度（`0` 为 8
位，非零为 16 位）、寄存器地址低/高字节、数据长度。读写长度最大为 16。
`0x63` 另有 `is_stop_bit`：`0` 使用重复起始，`1` 使用停止条件。

## 3. CRC8 校验

帧头 `0xAA 0x55` 不参与校验。CRC 从 Cmd 开始，覆盖 MotorID 和全部约定的
数据字节；短帧按实际固定长度计算。算法为 CRC-8/MAXIM 反射形式：初值 `0x00`，
多项式 `0x8C`。

```c
uint8_t crc8_maxim(const uint8_t *data, uint8_t length)
{
    uint8_t crc = 0;
    while (length--) {
        crc ^= *data++;
        for (uint8_t i = 0; i < 8; ++i) {
            crc = (crc & 1U) ? (uint8_t)((crc >> 1) ^ 0x8C) : (uint8_t)(crc >> 1);
        }
    }
    return crc;
}
```

校验失败、MotorID 不匹配或帧长不匹配的帧被丢弃，不产生响应。

## 4. 设置与控制命令

所有下表普通命令使用 12 字节 Data，响应命令为请求命令加 `0x10`。部分响应返回实际
生效值，部分响应回显请求值，具体以第 8 节逐命令说明为准。除特别说明外，写入参数
立即生效；标记“可保存”的参数通过保存命令写入 Flash。

| 请求 | 响应 | 功能 | Data 字段 |
| :---: | :---: | :--- | :--- |
| `0x00` | `0x10` | 电机开关 | Data0：`0` 关闭，`1` 开启 |
| `0x01` | `0x11` | 控制模式 | Data0：`1` 速度，`2` 位置，`3` 电流，`4` 编码器；可保存 |
| `0x02` | `0x12` | 过压保护恢复模式 | Data0：`0` 禁止自动恢复，非零允许自动恢复 |
| `0x03` | `0x13` | 堵转最大恢复次数 | Data0：最大自动恢复次数 |
| `0x04` | `0x14` | 速度模式堵转阈值和时间 | Data0~1：阈值；Data4：时间，单位 s |
| `0x05` | `0x15` | 位置模式堵转阈值和时间 | Data0~1：阈值；Data4：时间，单位 s |
| `0x06` | `0x16` | 解除保护 | Data0：非零解除过压；Data4：非零解除堵转 |
| `0x07` | `0x17` | 保存参数 | Data0：写 `1` 保存到 Flash |
| `0x08` | `0x18` | 编码器/旋钮计数 | Data0~3：小端有符号计数值 |
| `0x09` | `0x19` | 按键模式切换 | Data0：`0` 禁止，`1` 允许长按切换 |
| `0x0A` | `0x1A` | RGB 与亮度 | Data0~2：B/G/R；Data3：模式；Data4：亮度 `0~100` |
| `0x0B` | `0x1B` | RS485 波特率 | Data0：`0=115200`、`1=19200`、`2=9600`；可保存 |
| `0x0C` | `0x1C` | RS485 电机 ID | Data0：`0~255`；可保存 |
| `0x0D` | `0x1D` | 堵转保护 | Data0：`0` 禁止，`1` 允许；可保存 |
| `0x0E` | `0x1E` | 位置超范围保护 | Data0：`0` 禁止，`1` 允许；可保存 |
| `0x20` | `0x30` | 速度目标和最大电流 | Data0~3：速度 X100 rpm；Data4~7：电流 X100 mA |
| `0x21` | `0x31` | 速度 PID | Data0~3 Kp、Data4~7 Ki、Data8~11 Kd |
| `0x22` | `0x32` | 旧格式位置和最大电流 | Data0~3：位置 X100 度；Data4~7：电流 X100 mA |
| `0x23` | `0x33` | 位置 PID | Data0~3 Kp、Data4~7 Ki、Data8~11 Kd |
| `0x24` | `0x34` | 电流目标 | Data0~3：电流 X100 mA |
| `0x25` | `0x35` | 扩展目标位置和最大电流 | 见 4.1 |

### 4.1 扩展目标位置：`0x25 / 0x35`

请求 Data 和响应 Data 均为：

| 字节 | 字段 | 编码 |
| :---: | :--- | :--- |
| `0 ~ 3` | 目标圈数 | 小端 `int32_t` |
| `4 ~ 5` | 圈内角度 | 小端 `uint16_t`，单位 0.01 度，范围 `0~35999` |
| `6 ~ 7` | 保留 | 固定 `0` |
| `8 ~ 11` | 位置环最大电流 | 小端 `int32_t`，单位 X100 mA |

角度非法时不更新目标位置；响应返回当前有效目标和电流限制。扩展位置与旧格式
位置保持同步：`旧格式（0.01 度）= 圈数 * 36000 + 圈内角度`，超出旧格式范围
时旧格式按边界限幅。

## 5. 回读命令

回读请求使用 `Cmd MotorID 00 CRC8`（4 字节，不带帧头），响应为 20 字节，响应 Data
未使用的字节填 `0`。

| :---: | :---: | :--- |
| `0x40` | `0x50` | 速度 X100 rpm（0~3）；旧格式实际位置 X100 度（4~7）；实际电流 X100 mA（8~11）；模式（12）；系统状态（13）；错误码（14） |
| `0x44` | `0x54` | 实际圈数（0~3）；实际圈内角度（4~5）；目标圈数（8~11）；目标圈内角度（12~13） |
| `0x41` | `0x51` | VIN X100 V（0~3）；MCU 温度（4~7）；编码器计数（8~11）；RGB 模式（12）；亮度（13） |
| `0x42` | `0x52` | 速度 PID Kp/Ki/Kd（0~11）；RGB B/G/R（12~14） |
| `0x43` | `0x53` | 位置 PID Kp/Ki/Kd（0~11）；RS485 ID（12）；波特率档位（13）；按键模式（14） |
| `0x45` | `0x55` | STM32 UID Byte0~11；产品设备 ID（12，固定 `0x01`）；固件版本（13，固定 `3`）；Byte14 保留 |
| `0x46` | `0x56` | 速度最大电流（0~3）；位置最大电流（4~7）；电流目标（8~11） |
| `0x47` | `0x57` | 速度目标（0~3）；旧格式位置目标（4~7）；输出（8）；过压恢复（9）；堵转保护（10）；位置保护（11）；I2C 地址（12）；波特率档位（13）；按键模式（14） |

速度、电流和旧格式位置的 X100 原始值均按 `工程值 = 原始值 / 100` 换算。

## 6. RS485 转 I2C 命令

### 6.1 寄存器读写

`0x60` 请求 Data：`I2C 地址`、`寄存器地址长度`、`寄存器低字节`、`寄存器高字节`、
`读取长度`、保留；寄存器地址长度为 `0` 时使用 8 位地址，否则使用 16 位地址。
响应 `0x70` 的 Data0~1 为成功标志（小端，非零表示成功），Data2 为实际长度，
Data4~19 为最多 16 字节数据。

`0x61` 请求 Data0~21 为上述地址/长度字段和写入数据，最多写 16 字节；响应
`0x71` Data0 为成功标志。16 位寄存器地址按小端发送。

### 6.2 原始 I2C 读写

`0x62` 请求字段为 I2C 7 位地址、读取长度（最大 16）；`0x72` 返回成功标志、
实际长度和数据。`0x63` 请求字段为 I2C 地址、写入长度、`is_stop_bit` 和最多
16 字节数据；`0x73` 返回 Data0 成功标志。`is_stop_bit=0` 为重复起始，`1` 为
停止条件。

I2C 转发失败只影响该次转发，不改变 RS485 电机控制参数。所有转发帧仍使用本协议
CRC8，帧头不参与校验。

## 7. 状态和注意事项

- `0x50` 的系统状态：`0` 待机、`1` 运行、`2` 错误。
- 错误码 bit0 为过压、bit1 为堵转、bit2 为位置超范围。
- 过压或堵转保护状态可能拒绝电机使能或模式切换；先使用 `0x06` 解除堵转。
- `0x0B`、`0x0C` 修改通信参数时，设备完成当前响应后才切换；主机应随后使用新波特率
  或 ID。`0x0D`、`0x0E` 只修改保护开关，不改变通信配置。
- `0x07` 会写 Flash，避免高频调用；`0x17` 只是 `0x07` 的响应命令，不是独立请求。

## 8. 指令详情

本节逐条说明每个 Cmd 的请求数据、应答数据和注意事项。普通控制命令使用
12 字节 Data（`Req Data` 长度为 12），响应帧 `Data` 按命令返回生效值或请求回显；回读命令
使用 4 字节请求、20 字节响应；转发命令请求/响应长度见第 11 节。

### 8.1 电机开关 — `Cmd 0x00 / Resp 0x10`

#### 请求数据

Req Data 总长度：`12 byte`

| 数据 | 说明 |
| :--- | :--- |
| `Data0` | 电机输出：`0` 关闭，`1` 开启；立即生效 |
| `Data1~11` | 保留，填 `0` |

#### 应答数据

Resp Data 总长度：`12 byte`，`Data0` 为实际生效的电机输出状态（`0/1`），

#### 请求数据

## 9. 普通帧逐字节说明

普通请求帧不带帧头，Data 偏移从 `Data0` 开始，完整线上位置为：

| 线上字节 | 字段 | 说明 |
| :---: | :--- | :--- |
| `0` | Cmd | 请求命令 |
| `1` | MotorID | 目标电机 ID |
| `2~13` | Data0~Data11 | 命令数据 |
| `14` | CRC8 | `crc8(Cmd..Data11)` |

普通响应在线上位置 `0~1` 为 `AA 55`，从字节 `2` 开始使用 Cmd、MotorID 和 Data；
响应 Cmd 通常为请求 Cmd + `0x10`。例如 `0x20` 的响应为 `0x30`，响应 Data0~3
是实际速度目标，Data4~7 是实际速度电流限制。

### 9.1 控制命令的 Data 偏移

| Cmd | Data 偏移 | 类型/范围 | 说明 |
| :---: | :--- | :--- | :--- |
| `0x00` | Data0 | `0/1` | 输出关闭/开启 |
| `0x01` | Data0 | `1~4` | 速度/位置/电流/编码器模式 |
| `0x02` | Data0 | `0/非零` | 过压保护自动恢复模式 |
| `0x03` | Data0 | `0~255` | 堵转最大自动恢复次数 |
| `0x04` | Data0~1、Data4 | 阈值、秒 | 速度模式堵转阈值和时间 |
| `0x05` | Data0~1、Data4 | 阈值、秒 | 位置模式堵转阈值和时间 |
| `0x06` | Data0、Data4 | 非零 | 分别解除过压和堵转保护 |
| `0x07` | Data0 | 写 `1` | 保存全部可保存参数 |
| `0x08` | Data0~3 | `INT32` | 编码器/旋钮计数，小端 |
| `0x09` | Data0 | `0/1` | 按键模式切换 |
| `0x0A` | Data0~2 | `UINT8` | RGB B/G/R |
| `0x0A` | Data3 | `0/非零` | RGB 系统/用户模式 |
| `0x0A` | Data4 | `0~100` | RGB 亮度 |

## 11. 485 转 I2C 帧逐字节说明

### 11.1 寄存器读取：`0x60 / 0x70`

请求线上字节：

| 线上字节 | 字段 | 说明 |

| `3` | MotorID | 电机 ID |
| `4~5` | Success | 小端 `UINT16`，非零成功 |

### 11.3 原始读取：`0x62 / 0x72`

请求总长 5 字节：`62 MotorID I2CAddress ReadLength CRC8`，读取长度最大 16，且不带

### 11.4 原始写入：`0x63 / 0x73`

请求总长 25 字节，且不带帧头：

| 线上字节 | 字段 |
| :---: | :--- |
| `2` | I2C 7 位地址 |

| `8~23` | 写入数据，最多 16 字节 |
| `24` | CRC8 |

## 12. CRC 计算示例

```c
uint8_t crc8_maxim(const uint8_t *data, uint8_t length)
{
    uint8_t crc = 0;
    while (length--) {
        crc ^= *data++;
        for (uint8_t i = 0; i < 8; ++i) {
            crc = (crc & 1U) ? (uint8_t)((crc >> 1) ^ 0x8C) : (uint8_t)(crc >> 1);
        }
    }
    return crc;
}
```

15 字节普通请求调用 `crc8_maxim(&frame[0], 14)`；17 字节普通响应调用
`crc8_maxim(&frame[2], 14)`；4 字节回读请求调用 `crc8_maxim(&frame[0], 3)`；
20 字节回读响应调用 `crc8_maxim(&frame[2], 17)`；8 字节 `0x60` 请求调用
`crc8_maxim(&frame[0], 7)`；25 字节 `0x61/0x63` 请求调用
`crc8_maxim(&frame[0], 24)`；27 字节转发读响应调用
`crc8_maxim(&frame[2], 24)`。响应帧头 `AA 55` 永远不参与 CRC。

## 13. 建议通信流程

1. 使用当前 MotorID 和波特率发送查询帧。
2. 等待完整响应帧，按长度、帧头、MotorID 和 CRC 顺序校验。
3. 修改 ID 或波特率时，先保存响应，再切换主机配置。
4. 修改地址、PID、保护或目标后，使用对应回读命令验证实际生效值。
